# О проекте

WeakAuras — один из самых популярных аддонов для World of Warcraft, позволяющий создавать и импортировать собственные уведомления, таймеры, индикаторы, панели, анимации и 3D-модели.

Данная версия была специально адаптирована для сервера **UWOW.BIZ** и клиента **Legion 7.3.5**.

Основная цель UWOW Edition — исправление несовместимостей оригинальной версии, улучшение стабильности и корректная работа популярных WeakAura-сборок сообщества.

---

# Что изменено в версии 2.16.3.2 — UWOW Edition

### Исправлена работа шаблонов импорта

Исправлены проблемы совместимости при импорте WeakAura-настроек для Legion 7.3.5.

### Исправлено отображение WeakAuras

Устранены ошибки отображения пользовательских аур, групп и элементов интерфейса.

### Исправлена загрузка 3D-моделей

Исправлена работа DisplayID и ModelID, что позволяет корректно отображать модели существ, боссов, NPC и игровых объектов.

### Добавлены Mythic+ аффиксы

Во вкладку **«Загрузка»** добавлены условия для Mythic+ аффиксов Legion.

### Дополнительные изменения

# Установка

Распакуйте папку:

```text
WeakAuras
```

в каталог:

```text
World of Warcraft\Interface\AddOns\
```

В результате структура должна выглядеть следующим образом:

```text
World of Warcraft
└── Interface
    └── AddOns
        └── WeakAuras
```

После установки выполните команду:

```text
/reload
```

или полностью перезапустите игровой клиент.

# Как импортировать WeakAura

1. Откройте настройки аддона:

```text
/wa
```

2. Нажмите кнопку:

```text
Импорт
```

3. Скопируйте строку импорта с сайта Wago.
4. Вставьте её в окно импорта.
5. Нажмите:

```text
Импортировать
```
