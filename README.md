## О проекте

Коллекция адаптированных аддонов для World of Warcraft Legion 7.3.5, специально доработанных для сервера UWOW.BIZ.

### Основные изменения

* Адаптация аддонов под UWOW.BIZ
* Исправление Lua ошибок
* Улучшение совместимости с клиентом Legion 7.3.5
* Исправление работы WeakAuras
* Корректное отображение пользовательских аур
* Исправление загрузки и отображения 3D моделей
* Добавление Mythic+ аффиксов
* Оптимизация производительности
* Исправление интерфейсных ошибок

### Разработка

**Партной | Спиртной**

Разработка, адаптация, тестирование и сопровождение релизов.
